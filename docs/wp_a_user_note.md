# PEPL OS - What the system records about you

*Training-manual annex, Work Package A*

## One person, one login

Every person who uses PEPL OS has their own login. Logins are never shared, and a password is never
given to anyone else, including a colleague who is covering for you. The system records every action
against the login that did it, so a shared login makes you answerable for someone else's work.

## What is recorded

| When you... | The system records |
| --- | --- |
| Log in or log out | Time, and the network address you connected from |
| Change any field on a record | The field, the old value, the new value, who and when |
| Submit, cancel or amend a document | Who and when |
| Print, export or download | What was printed or exported, who and when |
| Open a sensitive record (System Parameters, Supplier Approval, Vendor Approval Status, Payment Tracker) | Who opened it and when |
| Delete something (System Manager only) | The full deleted record, who and when |
| Override a system rule | The rule, your reason in your own words, who and when |

Management can see all of this on one screen: **PEPL Audit Trail**.

## Deleting

Only the System Manager can delete. If something was entered wrongly, cancel it (for submitted
documents) or ask the System Manager.

## Overriding a rule

When the system stops you, for example with an unapproved supplier or a missing heat number,
you can continue only by typing a reason. Write a real reason ("Breakdown spare, MD approved on
phone"), because it is recorded with your name.
